# Hody kostkou
- Postavy maji **Dovednosti** od 0 nahoru. Dovednosti mohou prekrocit i 100
- Desitky v **Hodnote** dovednosti jsou **Bonus**, zapisují se jako DovednostB
	- *Napr.: Síla 64 -> SílaB 6*
- Cílem je hodit d100 pod svou Dovednost nebo presne jeji hodnotu, ale tak vysoko jak to jen jde
- Dvojice (11, 22, 33, 44...) jsou **Kriticke Uspechy** nebo **Kritické Neúspěchy**
	- 000 na kostce je vzdy (Kritický) Neúspěch.
		- Pokud je hodnota Dovednosti 100 a vyssi, je 000 pouze neuspech
- Mira (ne)uspechu (success level, **SL**) je odvozena od desítek na d100 hodu
	- Pri uspechu SL = hodnota na desitkove kostce
		- *Napr.: Dovednost 64, hod 57 -> Uspech, a 5 SL*
		- *Napr.: Dovednost 64, hod 07 -> Uspech, a 0 SL*
	- Pri neuspechu SL = desitkova hodnota Dovednosti  - hodnota na deitkove kostce
		- *Napr.: Dovednost 64, hod 68 -> Neuspech, a 0 SL*
		- *Napr.: Dovednost 46, hod 81 -> Neuspech, a -4 SL*
	- Pri hodech proti sobe se porovna SL obou oponentu, rozdil je mira uspesnosti (degree of success, **DoS**) viteze
		- Rozhodujici je kdo ma pozitivni DoS, ne to jestli hod uspel nebo neuspel
			- Lze tedy vyhrat , i pokud oba akteri selhali hod  --> dulezite je potom, kdo nasbíral mensi negativni SL.
			- V pripade shody DoS vyhrava Kritický  úspěch
		- *Napr.: Dovednost 64, hod 57 vs. Dovednost 46, hod 81 -> Dovednost 64 vyhrava, rozdil je 9 DoS*
		- *Napr.: Dovednost 64, hod 57 vs. Dovednost 46, hod 38 -> Dovednost 64 vyhrava, rozdil je 2 DoS*
		- *Napr.: Dovednost 64, hod 76 vs. Dovednost 46, hod 38 -> Dovednost 46 vyhrava, rozdil je 4 DoS*
		- *Napr.: Dovednost 64, hod 76 vs. Dovednost 46, hod 47 -> Dovednost 46 vyhrava, rozdil je 1 DoS*
		- *Napr. Dovednost 64, hod 66 vs. Dovednost 46, hod 47 -> Dovednost 64 vyhrava, rozdil je 0 DoS*
	- Kriticke uspechy a neuspechy pridavaji navíc +3 SL nebo -3 SL
		- *Napr.: Dovednost 64, hod 55 -> Uspech, 8 SL*
		- *Napr.: Dovednost 64, hod 77 -> Neuspech, -4 SL*
- Dovednosti nad Hodnotu 100 mohou selhat pouze př hodui 000, a každá další desítka na 100 se míto toho přičítá jako +SL k úspěšnému hodu
	- *Např.: Dovednost 132, hod 74 -> Uspěch, 7 + 3 SL*
# Vysledky akce podle SL

| Vysledek hodu (SL)    | Uspela akce?                             |
| --------------------- | ---------------------------------------- |
| 5 SL a vice           | Ano, lepe by to nikdo nezvladnul         |
| 3 az 4 SL             | Ano, toto je znamenity uspech            |
| 1 az 2 SL             | Ano, toto je uspech                      |
| 0 SL, hod byl uspesny | Ano, ale nastala nejaka komplikace       |
| 0 SL, hod byl uspesny | Ne, ale nestala nejake prizniva okolnost |
| - 1 az -2 SL          | Ne, toto je neuspech                     |
| -3 az -4 SL           | Ne, toto je hanebny neuspech             |
| -5 SL a mene          | Ne, takhle selhat, to svet nevidel       |
# Modifikátory
Modifikatory pridavaji nebo ubiraji efektivni hodnotu Dovednosti
- Mohou tak promenit uspech na neuspech, a naopak
	- *Napr.: Dovednost 64, hod 71, modifikator +20 -> Uspech, a 7 SL*
- Modifikatory meni Dovednost, ale ne jeji Bonus

| Narocnost cinnosti | Modifikator Dovednosti |
| ------------------ | ---------------------- |
| Velmi lehka        | +20                    |
| Lehka              | +10                    |
| Normalni           | +0                     |
| Tezka              | -10                    |
| Velmi tezka        | -20                    |
| Temer nemozna      | -30                    |
# Podpůrne Dovednosti
- Dovednost muze byt podporena Dovednosti jinou
	- Toto musi davat narativne smysl
	- Dvojnasobek Bonusu z jedne Dovednosti muze byt pridan jako modifikátor z hodu
		- *Napr.: Dovednost 64, podpůrná Dovednost 57 -> Dovednost 64 + (5 * 2) -> Efektivni Dovednost 74*
# Asistence
- Postava muze pomahat jine postave hodem na relevantni Dovednost
	- Uspesna asistence prida Vyhodu na hod
	- Neuspesna asistence vysledek neovlivni, ale...
		- Kriticky neuspech pri asistenci naopak zpusobi Nevyhodu
- Bezne muze jedne postave asistovat pouze jedna dalsi postava, pomoc od postavy treti a kadzde dalsi musi byt nalezite zduvodnena
# Momentum
- Skupinový zdroj
- Modifikátor +10 k jednomu hodu, před hodem
- K jednomu hodu lze použít nenajvýš 3 Momentum, pro +30 Modifikátor
- Použití Momentum je nutné nahlásit před hodem kostkou
# Odhodlání
- Osobní zdroj
- Lze utratit na
	- Získání +10 k jednomu hodu, 1 za 1, před hodem (jako Momentum)
	- Získání SL k výsledku jednoho hodu, 1 za 1
	- Zvýšení výsledku svého hodu na Iniciativu, 1 za 1
	- Vyhnout se upadnutí do Šoku, za 3 Odhodlání
	- Vyhnout se smrti pri neuspesném hodu na Umírání, za 3 Odhodlání
	- Vyhnout se okamzité smrti pri prekrocení svého Maxima Zranení, a místo toho zacit Umírat, za 3 Odhodlání
- Utracené Odhodlání se obnovuje mezi dobrodruzstvimi
- Maximum Odhodlání je 5 + 2x VůleB
- Unava snizuje tvé maximální Odhodlání
